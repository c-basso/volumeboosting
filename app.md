## Feature facts (safe to state on the website)

- Boosts volume up to 10× (shown in-app as "Volume multiplication x10" and a "Boost Volume to x10" button).
- Works with both audio and video files (MP3 and MP4/MOV shown in screenshots; "supports common file types").
- Optional "Improve Audio Quality" toggle (labelled "Not Stable" in the current build; describe as optional/experimental).
- Original / Processed A-B toggle to compare before saving.
- "Download Processed" saves the boosted file; the iOS share sheet offers Copy, Add Tags, Save to Files, and sharing to any app.
- Photos integration: create a project directly from the Photos share sheet.
- Keeps multiple projects in a list ("Volume Boost" home screen shows file name, size, and duration).
- Shows file metadata: Artist, Track, File Size, Duration.
- Processing happens on the device (no upload step in the flow).
- It processes files; it does not raise the iPhone's hardware speaker ceiling for system-wide audio.

## Positioning notes for the website

- The listing already targets "increase volume", "volume booster", "sound booster", "audio
  booster", "video volume booster". The website should own the *how-to* long tail these terms
  imply (see `keywords.md`).
- The strongest differentiators vs. iMovie/Photos: 10× (1000%) vs iMovie's ~500% ceiling,
  works on audio files as well as video, one-slider flow, share-sheet entry from Photos,
  keeps projects.
- Most common negative review theme is confusion with system volume. Every page should state
  plainly: the app makes the *file* louder; it does not change the iPhone's speaker limit.
