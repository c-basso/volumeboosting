よくある質問

よくある質問

まず短い答えを。それぞれスクリーンショット付きの詳しいガイドにつながります。

iPhoneで動画の音量を上げるには？

音量ブースターを開き、写真から動画を読み込む（またはアプリに共有する）、「音量倍率」を×10までドラッグ、「音量をブースト」をタップ、「オリジナル／処理後」を聴き比べて「処理後をダウンロード」をタップ。大きくなったコピーが写真またはファイルに保存され、どの端末でも大きく再生されます。

詳しく見る →

LINEやWhatsAppの音声メッセージが小さいのはなぜ？

全部小さいなら、近接センサーが覆われて受話口で再生されています。顔から離し、再生中に音量を上げてください。特定のメッセージだけ小さいなら、共有シートで書き出し、アプリで×5〜×10にブーストして、大きなコピーを保存・転送します。

詳しく見る →

画面収録の音が小さいのはなぜ？

iOSはアプリの音を下げたレベルで収録し、音量が低いときやBluetoothイヤホン接続時はさらに小さくなります。次回はBluetoothを切って音量を上げてから収録を。撮った収録は音量ブースターで×5〜×10にブーストできます。

詳しく見る →

ボイスメモの音を大きくするには？

ボイスメモの「録音を補正」は再生時のノイズを減らすだけで、ファイルは大きくなりません。録音をアプリに共有し（⋯ → 共有 → Increase Volume）、「音質を改善」をオンにして×5〜×10でブーストし、大きくなったM4Aを保存します。

詳しく見る →

パソコンなしでiPhoneのMP3の音量を上げられますか？

はい。ファイルアプリからMP3・M4A・WAVを追加し、倍率を選び、「オリジナル／処理後」を聴いて「処理後をダウンロード」をタップするだけ。大きくなったコピーはファイルに保存され、すべてiPhone内で完結します。

詳しく見る →

写真アプリで動画の音量を上げられますか？

写真アプリの編集でできるのは消音だけで、音量は上げられません。共有 → Increase Volumeで最大×10にブーストすると、大きくなったコピーが元の動画の隣に保存されます。

詳しく見る →

音量を上げると音割れしますか？

一番大きいピークがデジタルの上限を超えたときだけです。小さい録音には十分な余裕があります。×3から始め、「オリジナル／処理後」で一番大きい瞬間を聴き、きれいなうちは上げていきましょう。映像は一切変わりません。

詳しく見る →

iMovieの音量調整との違いは？

iPhoneのiMovieは約500%（5倍）が上限で、プロジェクト作成と全体の書き出しが必要です。音量ブースターは×10（1000%）まで上げられ、音声ファイルも開け、保存前に「オリジナル／処理後」で確認できます。

詳しく見る →

アプリでiPhoneのスピーカー自体が大きくなりますか？

なりません。スピーカーの物理的な上限を超えたり、システム全体の音量を変えたりできるアプリはありません。このアプリはファイルを大きくするため、録音そのものが小さいときに役立ちます。どの動画も小さいなら、まず再生側の原因を確認してください。

詳しく見る →

音量ブースターの料金は？

ダウンロードは無料で、無料トライアルがあります。無制限のブーストはサブスクリプションで利用できます。最新の価格はApp Storeで円表示で確認できます。処理は常にお使いのiPhone内で行われます。

ファイルはサーバーにアップロードされますか？

されません。処理はiPhone内で行われ、アカウントもアップロードも不要です。結果はiOSの共有シートで写真・ファイル・お好きなアプリに保存されます。
