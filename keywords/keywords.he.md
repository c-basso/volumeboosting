# Keyword research and page map — Hebrew (he) — volumeboosting.com/he/

Goal: same as `keywords.md` — rank for Hebrew queries (Israel) from people with a quiet file on
their iPhone right now. Pages are RTL (`dir="rtl"`), plural address («פתחו», «הקישו») per
`glossary.tsv`.

Method (2026-10-02): Hebrew SERP checks, the IL App Store listing (`?l=he`, localized:
"מגביר עוצמת קול" / "לשמע חלש ושקט"), Apple's Hebrew app names where verifiable, and the English
map. No keyword-volume tool; tiers are directional (Hebrew ≈ 1/25–1/40 of US English demand).
Validate in Search Console (filter `/he/`).

Tiers: **High** ≈ 500+/mo, **Medium** ≈ 100–500, **Low** ≈ 20–100, **Niche** < 20.

## 0. What the IL storefront shows (2026-10-02)

- Hebrew title/subtitle and description; 3.3★ from 3 ratings in IL.
- **Screenshots are not localized**: the Hebrew listing serves the English set (6 images, no
  "projects" screen). The site keeps the shared `/img/screenshots/1–7.webp`; no `img/screenshots/he/`.
- IAPs (IL): weekly subscription with free trial; annual subscription ₪63.90. No lifetime option
  shown, so Hebrew copy says «מינוי» only.
- Site brand line ("Increase Volume – הגברת שמע") differs from the store title; guides use the store
  name «מגביר עוצמת קול» so searchers recognise the listing.

## 1. SERP observations

- "איך להגביר עוצמת קול בסרטון באייפון": thin — HeyGen tool page, spammy English pages, no native
  Hebrew iPhone answer → strong opportunity.
- "הקלטת מסך אייפון קול חלש": CapCut/Transkriptor content farms; no direct fix page.
- Phrasing: «להגביר קול / עוצמה / ווליום», «קול חלש», «שקט», «לא שומעים». Users write «אייפון» far
  more than "iPhone" — titles use «אייפון».
- Apple Hebrew names used: תמונות, קבצים, **תזכורות קוליות** (verified via support.apple.com/he-il;
  note `glossary.tsv` says «זיכרונות קוליים» — update the glossary), מרכז הבקרה, הקלטת מסך, iMovie.
- **Verify on a Hebrew iPhone** (not confirmed from Apple docs): ״צלילים ומשוב הפטי›בטיחות אוזניות›
  הפחתת צלילים חזקים״, ״מוזיקה›בדיקת צליל״, EQ «לילה מאוחר», ״נגישות›שמע וחזותי›איזון״, ״Face ID וקוד״,
  ״שיפור הקלטה״, ״מיקס שמע״.
